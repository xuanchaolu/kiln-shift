Firing Color Transform

烧制前后色盘的颜色变换：规律、公式与精度上限

01结论先行

先给答案，再给证据。

  1. 变化的主方向是"变暗 + 变浓 + 偏黄"，中段可以用一条逐通道线性式概括： 三个通道各自做一次斜率大于 1、截距为负的拉伸。这与"对比度提高、蓝通道被压得最狠"是同一件事。
  2. 但这条直线不能在两端直接外推。照片里同一张白标签从 #FDFDFC 到 #FCFAF8，几乎没动；而直线外推到 255 会给出发黄的 #FFFFF1。所以公式在两端被拉回不动点：纯黑仍黑，纯白仍白。
  3. 最终公式仍是 6 个参数，只是在两端加了一个权重：留一交叉验证 R² = 0.63， 平均误差 12.1 ΔE00（纯线性为 12.74），最差 10% 的误差 20。 换成 12 参数耦合矩阵、Lab 空间仿射、幂律、二次项、随机森林后误差都在 12.4–15.8 之间， 没有实质差别——所以保留最简形式。
  4. 误差不能再降，原因不在模型，在数据信息量。三个硬约束： 变量缺失造成"同色异果"（下界 15.7 ΔE00）、 取样噪声（同一块釉面两框相差中位 4.4、烧制后 P90 达 15.5 ΔE00）、 以及两照片本身的成像差异。
  5. 结论的用法：这套公式适合"给任意颜色预演它在 1300℃ 烧成后会变成什么样"（做设计预览、批次粗筛）， 不适合"逐格精确预测"（每格都有独立的釉料配方与堆积厚度）。要再进一步，必须把配方/位置等非颜色信息纳入模型。

02数据与核验

43 种颜色，每种在两张照片中各框选 2 处，取框内全部像素的 RGB 均值（按像素数加权合并）。 分析前先做了两件事，避免在脏数据上建模型：

  • 数值复核：用 CSV 里的框坐标回原图（1280×1708）重新统计像素均值，与 CSV 的最大偏差 0.083（纯舍入），说明标注数据与像素统计一致。
  • 取样噪声测量：同色两框本应相同，实测相差中位 2.1 ΔE00（before）、 7.8 ΔE00（after）。烧制后釉面内部的颜色梯度明显变大，这是后面误差的主要来源之一。
一个必须说明的前提：两张照片是手机拍摄的，白平衡、曝光、镜头位置都不同。 "before → after"的差异里，混有真实的釉面变化与成像差异两部分，本数据无法完全分离。 因此下文的公式准确说应理解为「两张照片之间的颜色映射」， 在工艺上它是"釉色变化 + 拍摄条件变化"的合成结果。

03变化长什么样

先把规律看清楚，再谈拟合。

3.1 逐通道：一条比 y = x 更陡的直线

把每个通道的 before 值作横轴、after 值作纵轴，点几乎沿着一条比对角线更陡的直线排列。 斜率大于 1 且截距为负，意味着越暗的颜色掉的越多、接近白的几乎不动—— 这就是"对比度提高"，在视觉上表现为颜色更深、更艳。

3.2 在感知空间里：整体下沉、色度外扩

换算到 CIELAB：ΔL* 43 个样本全部为负（中位 -14.6）， ΔC* 有 93% 为正（中位 18.8），色相基本保持（|Δh| 中位 15°）。 也就是说烧制的主要作用是把颜色压暗、把彩度推高，而不是大幅改变色调。

3.3 明度两极：从照片里直接量出来的约束

43 个釉色样本只覆盖了中间调（各通道 55–238），两端没有数据，模型只能外推。 好在两张照片里都有同一类物体——色盘中心的白色纸标签、大面积浅色纸面、最暗的背景—— 可以直接量出两极应该怎么映射：

两个发现：① 白几乎不动（ΔE 仅 1.0），直线的"斜率 × 截距"外推到 255 却会给出 14–30 的蓝偏， 这正是"越白越黄"的来源；② 黑被压到接近 0，说明后期这张照片对比更强， 直线在暗端的方向是对的，只是不够狠。所以修正在两端做：让曲线在 0 与 255 处严格回到恒等。

需要注意：这里的"白"是白色颜料，不是釉。浅色釉块（如颜色 1）在同一亮度上确实会变黄。 两者矛盾（见第 6 节），公式只能在中间取一个折中。

04最终公式

6 个参数加两个常数，纯四则运算，可直接写进任何程序。

① 逐通道（有色釉走这条）
x₁ = a·x + b    w = C·t0.746·(1−t)1.165，C = 3.5905，t = x/255
y₁ = x + K·w·(x₁ − x)，K = 1.25
② 亮度路径（近中性灰走这条）
L = 0.2126R + 0.7152G + 0.0722B    L₂ = L + K·w·(1.6872·L − 174.40 − L)
y₂ = L₂ + S·(x − L)，S = 2.0
③ 按彩度混合
ω = min(1, max(0, (max−min − 6)/34))    ω = max(ω, min(1, max(0, (L − 160)/40)))
y = y₂ + ω·(y₁ − y₂)
三条通道各有斜率时，中性灰会被"三路各走各的"染成暗橙（例如 152,150,145 会被算成 104,60,21）。 所以低彩度改走亮度路径：亮度按同一套权重下降，色度按 S 等比展开，灰就不再偏色（同一输入变成 80,72,59，与实测 86,73,63 接近）。 有彩度的釉（通道差 > 40）仍走逐通道，保住"变黄"；很亮的像素（L > 200）也强制走逐通道，浅色釉才不会失去黄化。 K = 1 时两端回到"不变"，K = 1.25 把变化量放大四分之一，x = 0 与 x = 255 始终严格不动。

三通道的直线参数如下。必须先算直线、再按权重混合、最后乘 K，顺序不能反。

通道a（斜率）b（截距）不动点 b/(1−a)含义
R1.535−126.2236 红通道压得最轻
G1.936−223.9239 居中
B1.890−241.2271 蓝通道压得最狠，整体因此偏黄

4.1 直接可用的代码

# 烧制前 → 烧制后（1300℃），输入输出均为 0-255
A = (1.5348, 1.9364, 1.8902)
B = (-126.22, -223.93, -241.17)
K, S = 1.25, 2.0
AY, BY = 1.6872, -174.40

def weight(v):
    t = v / 255.0
    return 3.5905 * t**0.746 * (1 - t)**1.165

def curve(v, a, b):
    w = weight(v)
    base = (1 - w) * v + w * (a * v + b)
    return v + K * (base - v)

def before_to_after(rgb):
    r, g, b = rgb
    L = 0.2126 * r + 0.7152 * g + 0.0722 * b
    L2 = curve(L, AY, BY)
    p1 = [curve(v, A[i], B[i]) for i, v in enumerate(rgb)]
    p2 = [L2 + S * (v - L) for v in rgb]
    w = max(min(1, max(0, (max(rgb) - min(rgb) - 6) / 34)),
            min(1, max(0, (L - 160) / 40)))
    return tuple(max(0.0, min(255.0, q + w * (p - q))) for q, p in zip(p2, p1))

反向（由烧成色推初始釉色）：正向输出的亮度恒等于 L₂，所以先用它反查 L 再还原色度； 彩度很高的像素退回逐通道二分。往返误差彩色为 0，近中性 ≤ 2；被压到 0 的暗部无法还原，这是截断本身的信息损失。

4.2 系数的可信区间

用 2000 次自助法（bootstrap）重采样估计 a、b 的不确定性。斜率稳定；截距区间较宽， 因为斜率与截距高度互补（同一条直线可由不同组合给出），两者必须一起用。

06为什么换更复杂的模型也不行

这不是调参不努力，而是数据里存在不可约的误差。三条独立证据：

6.1 同色异果：同样的 before，变成不同的 after

颜色 1 的 before 是 #D4D7D4，颜色 26 是 #C6CDC9， 两者仅相差 3.6 ΔE00（肉眼几乎一样）；但它们的 after 分别是 #DBC59D（明显偏黄）与 #C5CCCB（几乎不变）， 相距 16.5 ΔE00。

一个只看 RGB 的函数，对几乎相同的输入只能给出几乎相同的输出。这件事可以量化成硬下界： 在 before 相距小于 3 ΔE00 的 23 对样本中，after 相距的中位数就有 12.0 ΔE00； 差别最大的一对（#17 与 #21）before 相距 2.4、after 相距 32.2。 由三角不等式，无论公式怎么取，这两点中至少有一点的误差 ≥ (32.2 − 2.4)/2 ≈ 15.7 ΔE00。 也就是说，误差不是靠模型变复杂就能消掉的，12.1 的平均误差已经接近这张数据集的物理天花板。

这条证据同时说明：釉色的最终结果并不由"初始看起来是什么颜色"决定， 而由釉料配方、施釉厚度、在窑内的位置决定。两个看起来同色的格子，可能是完全不同的配方。

同样的矛盾在第 3.3 节的白标签上再次出现，而且更极端：颜色 1 的浅粉釉（#D4D7D4） 烧后变黄，同一亮度的白色纸标签（#D6DAD6）却几乎不变。 这就是为什么公式在两端只能取折中——把白端钉死，浅色釉块就会预测得不够黄，反之亦然。

6.2 取样噪声：同一块釉面自己也对不上

同一个颜色格里的两个框，本应完全一致，实际相差 before 中位 2.1、 after 中位 7.8 ΔE00（P90 高达 15.5）。 after 图的釉面内部梯度更大（釉料在高温下流动、堆积），"这一格的颜色"其实是一个分布而非一个点。 目标值本身带 ±7.8 的抖动，公式再准也无从对齐。

6.3 两次拍摄的成像差异

两张照片由手机在不同距离、不同光线下拍摄，白平衡与曝光没有标定。 公式中"蓝通道整体压低"这一项，部分可能来自拍摄条件而非釉面本身。 若要分离二者，需要在两次拍摄中都放入同一块中性灰/白参考卡，并把相机设为手动固定参数。

07建议与下一步

  • 现在就能用：把 4.2 的函数嵌进设计工具，输入任意釉色即可预览 1300℃ 烧成后的走向； 或者反过来做"目标色 → 该选什么初始釉色"的粗筛。
  • 要提升精度，必须加特征而不是换模型：优先补 ① 每格釉料配方/编号， ② 该格在窑内的位置（边缘/中心、上下层），③ 施釉厚度。经验上这三项能把误差从 12 降到个位数。
  • 采集规范：下一次拍摄用固定机位、固定光源，画面里放同一张灰卡； 每个色格改为框 3–4 处并取中位，可把取样噪声压到 2–3 ΔE00，公式的上限随之提高。
